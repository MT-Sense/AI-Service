# AI-Service

วิเคราะห์ข้อความแบบสำรวจของ MT-Sense ด้วยโมเดล sentiment และ Gemini สำหรับจัดหมวดหัวข้อ
Backend ส่งข้อความที่ลบข้อมูลระบุตัวตนแล้วมาที่ `POST /analyze` และใช้ผลลัพธ์บันทึก
ใน `response_analysis` หมวดที่ส่งกลับเป็นรหัสเดียวกับ Backend:
`work`, `team`, `manager`, `compensation`, `growth`, `benefits`.
ชื่อคลาส sentiment ที่ส่งไป Backend คือ `pos`, `neg`, `neu` โดยโมเดลเก่าที่ใช้
`nau` จะถูกแปลงเป็น `neu` ก่อนส่งออก และสคริปต์ฝึกจะใช้ `neu` สำหรับโมเดลใหม่

## เริ่มใช้งาน

จากโฟลเดอร์ `AI-Service`:

```bash
python3 -m venv venv
venv/bin/pip install -r Requirements.txt
```

สร้าง `.env` ที่มี `GEMINI_API_KEY` แล้วเริ่มบริการ:

```bash
venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

ตรวจสถานะได้ที่ `http://127.0.0.1:8000/health` และดูรูปแบบ API ที่
`http://127.0.0.1:8000/docs` ก่อนส่งแบบสำรวจ ให้เริ่ม AI-Service และ Backend-Service
ทั้งคู่ หลังแก้โค้ดต้องเริ่มกระบวนการที่กำลังรันอยู่ใหม่เพื่อโหลดโค้ดล่าสุด

## คำที่ถูกพูดถึงบ่อย

Backend ส่งข้อความแบบสำรวจที่ปกปิดข้อมูลระบุตัวตนแล้วไปยัง `POST /keywords`
เพื่อแยกคำภาษาไทยด้วย PyThaiNLP และกรองคำทั่วไป เช่น `ใช่`, `ไม่`, `ดี`,
`ดีมาก`, `ครับ` รวมถึงตัวเลขและข้อความที่ถูกปกปิด จากนั้น Backend นับคำหนึ่งครั้ง
ต่อหนึ่งคำตอบ และแสดงเฉพาะคำที่พบในอย่างน้อย 5 คำตอบของรอบสำรวจเดียวกัน
ส่วนนี้อ่านจากข้อความจริง ไม่ใช้ `word_cloud_terms` ซึ่งเป็นข้อมูลตัวอย่างเดิม

## ทดสอบผ่านหน้าเว็บ

ล็อกอินเป็นพนักงาน เปิด sidebar **My Surveys / แบบสอบถามของฉัน** กรอกคะแนนและ
ข้อความ แล้วกดส่ง ผล sentiment ของคำตอบใหม่จะปรากฏใน **HR Dashboard** เมื่อมีข้อมูล
เพียงพอตามกฎความเป็นส่วนตัว (กลุ่มที่มีผู้ตอบต่ำกว่า 5 คนถูกซ่อน)

## ฝึกโมเดลผ่านหน้าเว็บ

กำหนด `AI_TRAINING_TOKEN` ให้มีค่าเดียวกันใน `AI-Service/.env` และ
`Backend-Service/.env` แล้วเริ่มบริการทั้งสองใหม่ ล็อกอินด้วยบัญชี HR
`Test@test.com` เปิดเมนู **ฝึกโมเดล Sentiment** เลือกไฟล์ `.xlsx` ที่มีคอลัมน์
ความคิดเห็นและ `Sentiment` แล้วกด **Train model** ผล accuracy และ macro F1
จากชุดทดสอบจะแสดงบนหน้าเว็บ หลังประเมิน ระบบจะฝึกด้วยข้อมูลที่ใช้ได้ทั้งหมด
บันทึกไฟล์โมเดล และเปลี่ยนโมเดลที่ AI-Service ใช้ทันที บัญชี HR อื่นใช้เมนูนี้ไม่ได้
